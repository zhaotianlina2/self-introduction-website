# 赵天林 · 个人介绍网站

这是一个以单页网页呈现赵天林学习经历、软硬协同技能与项目介绍的个人作品集，帮助招聘方和协作伙伴快速了解其背景与实践方向。

## 页面内容

- **个人简介**：展示计算机科学与技术（软硬协同方向）学习背景、竞赛经历和技能概况。
- **技能卡片**：介绍 C/C++、Python、嵌入式开发、I²C/SPI/UART、EDA 工具及信号处理等方向。
- **经历时间线**：按时间展示竞赛、校园经历与学习背景。
- **项目展示**：介绍过程装备测控、电子设计竞赛控制系统和数学建模项目。
- **个人特质与问答区**：页面包含特质介绍和交互式问答界面。
- **联系区**：页面提供联系入口。出于隐私考虑，本说明不复制页面中的个人联系方式。

## 界面与交互

页面采用暖色背景、粗描边卡片和内嵌 SVG 插画构成的平面插画风格，并以响应式布局适配较窄屏幕。首屏通过鼠标位置控制的双层中英文遮罩呈现互动效果；导航链接定位到页面区块，内容随滚动显现，卡片带有悬停状态。

## 技术实现

- 原生 HTML、CSS 与 JavaScript，全部页面结构、样式和交互写在 `index.html` 中。
- 字体通过 jsDelivr 加载 Fontsource 的 Bricolage Grotesque、Nunito Sans 与 Noto Sans SC。
- 页面插画与项目缩略图使用内嵌 SVG；仓库没有独立截图或媒体文件。
- `update-links.py` 是针对 `/mnt/cos/artifacts/intern-intro.html` 的定向替换脚本，不是网站启动程序；运行前应先确认该输入文件确实存在并已备份。

## 本地预览

这是一个静态网页仓库，没有包管理清单或构建配置。可以直接在浏览器打开 `index.html`；也可在仓库根目录启动 Python 的静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。页面使用的字体来自外部 CDN；离线访问时字体可能无法加载。
